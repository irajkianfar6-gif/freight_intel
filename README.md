# Freight Intel
ابزار پایش و پیش‌بینی تقاضای حمل بین‌المللی و ترانزیت با مبدا ایران، فقط بر پایه داده‌های عمومی (OSINT).

## مسیر داده
```
منابع (زمان‌بندی‌شده) → ذخیره خام (SQLite) → نرمال‌سازی فارسی → سیگنال‌های قطعی H1–H6
  + شاخص‌های پیش‌نگر شرکت (I1–I3, I5, I7–I9) + شاخص‌های بخش و کریدور (I4, I6, I10)
→ تطبیق هویت (شناسه ملی) → راستی‌آزمایی V0–V3 + غربالگری تحریمی
→ امتیاز تقاضا، عوامل منفی، پنجره زمانی، احتمال کالیبره‌شده → کارت سرنخ (JSON / CSV / Excel / monday)
```

## شروع سریع
```bash
pip install -r requirements.txt
python -m unittest discover tests                    # ۳۱ تست
python -m freight_intel.cli demo --today 2026-11-16  # اجرای کامل روی داده ساختگی، بدون اینترنت
```

## اجرای عملیاتی
```bash
cp config.yaml my.yaml                     # منابع را پر کنید
export OPENSANCTIONS_API_KEY=...           # بدون کلید، هیچ سرنخی آماده ارسال به فروش نمی‌شود
python -m freight_intel.cli run --config my.yaml --due-only --out outputs
python -m freight_intel.cli status --config my.yaml          # آخرین اجرا و خطای هر منبع
export MONDAY_API_TOKEN=...
python -m freight_intel.cli push-monday --board <BOARD_ID>   # ارسال و به‌روزرسانی در monday
python -m freight_intel.cli calibrate --config my.yaml --from-monday --board <BOARD_ID>
```
اجرای دائمی: `docker build -t freight-intel . && docker run -v $PWD/data:/app/data -e MONDAY_BOARD_ID=... freight-intel`
یا `deploy/crontab.example`.

## تناوب پایش (قابل تغییر با `every_hours`)
| منبع | تناوب |
|---|---|
| تلگرام | ساعتی |
| بورس‌های بار | ۶ ساعت |
| مناقصات | ۱۲ ساعت |
| اخبار، کدال، بورس کالا، روزنامه رسمی، AIS | روزانه |
| استخدام، B2B | هفتگی |
| نمایشگاه‌ها، Comtrade | ماهانه |

اجرای ناموفق در دور بعد دوباره انجام می‌شود.

## ماژول‌ها
| ماژول | کار |
|---|---|
| `normalize`، `jalali` | نرمال‌سازی فارسی، تاریخ شمسی در هر دو جهت |
| `patterns`، `extract` | الگوهای H1 تا H6، تناژ، کانتینر، اینکوترمز، مرز، مقصد، کالا و HS، رویدادهای I3، I5، I7 و I8 |
| `sector` | I6 (تعرفه، ممنوعیت، توافق تجاری) و I10 (مسیر جدید، ازدحام، بسته شدن مرز) با جهت مثبت یا منفی |
| `scoring` | وزن‌ها، کاهش نمایی، هم‌افزایی، سقف تنوع منبع، پنجره زمانی، شاخص‌های I1، I2، I3، I4 و I9 |
| `verify`، `resolve`، `sanctions`، `confidence` | ماتریس راستی‌آزمایی، تشخیص واسطه، تطبیق نام، OpenSanctions، کسر امتیاز با دلیل |
| `leads` | کارت سرنخ با شناسه پایدار، اثر عوامل منفی (هر عامل ×۰.۸، کف ×۰.۵) |
| `calibration` | رگرسیون لجستیک روی نتایج واقعی، Brier و reliability، احتمال ۶ ماهه |
| `report_xlsx`، `monday_export` | Excel راست‌به‌چپ، ارسال به monday و دریافت نتیجه‌ها برای کالیبراسیون |
| `sources/*` | t.me/s، Telethon، RSS و Google News، کدال (افشا و گزارش ماهانه)، بورس کالا (Excel و Playwright)، روزنامه رسمی (CSV)، صفحات فهرستی، Comtrade، AIS |

## پیش از استفاده واقعی
- **selectorها:** selectorهای صفحات فهرستی، دستورالعمل Playwright بورس کالا و endpoint سرویس AIS را روی سایت زنده تنظیم کنید.
- **کدال:**
  - endpoint جستجوی کدال مستند نشده است.
  - پارسر گزارش ماهانه heuristic است و فیلد `confidence` برمی‌گرداند. ارقام هر شرکت را بار اول دستی کنترل کنید.
- **روزنامه رسمی و شناسه ملی:** کپچا دارند، پس استعلام دستی انجام می‌شود و نتیجه در `registry.csv` و CSV آگهی‌ها ثبت می‌شود.
- **AIS:** پولی است و کشتی‌های ایرانی اغلب آن را خاموش می‌کنند. فقط روند را بسنجید، نه حجم.
- **Comtrade:** کلید رایگان لازم دارد و داده آن با تاخیر منتشر می‌شود.
- **تقویم فصلی و فهرست‌ها:** تقویم فصلی (`SEASONAL_EXPORT_MONTHS`) و فهرست مرزها و کالاها تقریبی‌اند و باید سالانه بازبینی شوند.
- **لینکدین:** خزش نمی‌شود.
- **تحریم:** غربالگری تحریمی تصمیم حقوقی نیست. تطابق احتمالی را به واحد حقوقی ارجاع دهید.
- **کالیبراسیون:** حداقل ۲۰۰ سرنخ با نتیجه مشخص لازم دارد. تا آن زمان وزن‌های کارشناسی به کار می‌روند.
- **داده تست:** همه رکوردهای `tests/fixtures` ساختگی‌اند.

## برد monday
ستون‌ها با عنوان پیدا می‌شوند:
- **شناسایی:** شناسه سرنخ، شناسه ملی، صنعت
- **تقاضا:** نوع نیاز، طبقه تقاضا، امتیاز تقاضا، بازه حمل
- **محموله:** کالا، کد HS، تناژ یا حجم، واحد، مرز یا بندر خروجی، کشور مقصد، شیوه حمل
- **اعتبارسنجی:** سطح راستی‌آزمایی، غربالگری تحریمی، امتیاز اطمینان، دلایل کسر امتیاز
- **مستندات:** شواهد و منابع، نیازمند استعلام
- **پیگیری:** وضعیت پیگیری

برچسب‌های «وضعیت پیگیری» برای کالیبراسیون: جدید، در حال تماس، پیشنهاد قیمت، برنده، از دست رفته.
